# Knowledge Base — moved

The personal knowledge base (Postgres + pgvector + local LLM) and the
Instagram saved-posts sync that this tutorial used to document were
extracted whole — code and the real production data (3403 documents, 12755
chunks, 12755 embeddings) — into their own project in 2026-10-06:

**[`insta_kb`](https://github.com/leonardodg/insta_kb)**

Its [README](https://github.com/leonardodg/insta_kb#readme) covers the same
ground this page used to: the tools reference, recommended flows, database
structure, Instagram sync, configuration, and troubleshooting — kept
up to date against that repo's actual code, which this one no longer has.

This repo (`minimax-video-factory`) is video-generation only now. See the
[Module Guide](dev/modules.md) for what's left.
